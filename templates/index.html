01 — CONCEPTO

¿Qué es Python?

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general.

Fue diseñado para que el código fuera relativamente sencillo de escribir y leer. Gracias a esto se convirtió en una herramienta muy utilizada tanto por personas que están comenzando a programar como por desarrolladores profesionales.

Python puede utilizarse para crear aplicaciones, automatizar tareas, analizar información, desarrollar páginas web, trabajar con inteligencia artificial y construir herramientas para diferentes áreas.

¿Por qué es importante?

  • ✔ Fácil de aprender
  • ✔ Gran cantidad de librerías
  • ✔ Comunidad mundial
  • ✔ Multiplataforma
  • ✔ Utilizado profesionalmente

02 — HISTORIA Y EVOLUCIÓN

El camino de Python

1989

Comienza el proyecto

Guido van Rossum comenzó a trabajar en Python como un proyecto para crear un lenguaje sencillo y potente.

1991

Python aparece públicamente

Se publica la primera versión de Python y comienza a desarrollarse su comunidad.

2000

Python 2

Python 2 introdujo numerosas mejoras y fue utilizado durante muchos años.

2008

Python 3

Aparece Python 3 con cambios importantes y se convierte en la rama principal del lenguaje.

Actualidad

Python en todas partes

Actualmente se utiliza en desarrollo web, inteligencia artificial, ciencia de datos, automatización y educación.

Python 2 vs Python 3

Python 2

Versión antigua que dejó de recibir soporte oficial en 2020.

Python 3

Rama moderna utilizada actualmente y que continúa recibiendo actualizaciones.

09 — LICENCIA

Python es Open Source

Python es software de código abierto. Esto significa que su código fuente está disponible y que existe una comunidad mundial que contribuye a su desarrollo.

Python se distribuye bajo una licencia que permite utilizarlo, modificarlo y distribuirlo respetando sus condiciones.
